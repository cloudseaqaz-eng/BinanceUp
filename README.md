# BinanceUp 回测代码包

点击本分支中的 `BinanceUp-research.zip`，使用 GitHub 的 Download raw file 按钮下载并解压。

包内包含慢层8项评分、六个月归档下载、首次进入前10的标签、权重搜索、概率校准和前端排名/详情/报告页面。使用步骤见包内 `BinanceUp/RESEARCH.md`；实际验证范围见 `RESEARCH_VALIDATION.md`。

28项自动检查、24项浏览器检查已通过。真实BTC归档已做小范围验证；云环境无法访问全历史目录，因此没有宣称已完成真实全市场六个月回测。

包内不含个人数据、下载缓存或模拟数据集；可通过说明中的 demo 命令生成独立演示。

校验值见 `SHA256SUMS`。
